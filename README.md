Descrição
Projeto desenvolvido para a disciplina de Front-End, com o objetivo de criar um site multipágina para uma empresa fictícia de viagens.
Evolução do Projeto
No Checkpoint 1, o foco foi a estrutura HTML, páginas, navegação, formulário e colaboração com GitHub.

No Checkpoint 2, o projeto foi evoluído com:

CSS externo (css/style.css)
Variáveis CSS com :root
Identidade visual completa com paleta de cores e tipografia
Layout com Flexbox em todas as páginas
Cards responsivos para destinos e pacotes
Pseudo-classes (:hover, :focus)
Medidas relativas (rem, %, vh, vw, clamp)
Responsividade com @media para desktop, tablet e celular
Formulário estilizado com labels, inputs e botão
Header fixo com navegação horizontal
Footer completo com links e informações de contato
